# C# Command-Line Calculator Application

This is a functional console-based calculator program I built in C# for my college programming lab. It prompts users for numerical inputs and executes core mathematical operations based on user selection.

## Key Features & Logic:
* **Switch-Case Architecture:** Implemented a robust `switch` statement to efficiently evaluate and route user-selected arithmetic operations (+, -, *, /).
* **Data Input & Type Conversion:** Handled user terminal inputs and utilized `Convert.ToInt32` to successfully parse string entries into workable integers.
* **Error Handling:** Designed a fallback `default` condition to gracefully catch invalid operator inputs and prevent application crashes.

## Technologies Used:
* **Language:** C#
* **Framework:** .NET Console App
* **IDE:** Visual Studio
